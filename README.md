# Capsule Sortie

Godot 4 기반 SD 건담 캡슐파이터 팬게임 — Showcase Candidate 1.

[시연 소개](https://yum-sy.github.io/sd-capsule-fighter-demo/showcase.html) · [플레이](https://yum-sy.github.io/sd-capsule-fighter-demo/) · [개발·조작·검증 문서](sd-capsule/README.md) · [에셋 크레딧](sd-capsule/CREDITS.txt)

실제 무료 SD 모델과 양 기체 관절 애니메이션, 모션과 판정이 연동된 사벨 전투, 전장 2종과 역할별 자쿠 AI, 파괴 가능한 엄폐물·선택 목표·표준/베테랑 난이도, 3기 자쿠 AI, PC·터치 입력, 오프라인 PWA를 포함합니다.
모바일 실기기 성능 및 iOS 설치 검증은 개발 문서의 미완료 항목을 확인하세요.

시연 화면·HUD·결과 화면을 재구성하고 초반 상황 안내·한국어 가이드·엄폐 표적 방향 안내를 추가했습니다. 제작 일정, 검증 기록과 외부 시연 승인 기준은 개발 문서에 있습니다. 현재는 내부 검토용 시연 후보이며, 건담 IP 사업화 권리를 확보했다는 의미가 아닙니다.
